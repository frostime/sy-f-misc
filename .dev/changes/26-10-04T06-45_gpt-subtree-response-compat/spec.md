# GPT 子树操作与响应兼容性

## 已确认范围

- 完整对话树提供明确的浏览/选择两个状态；选择集合不受预设 root 或路径模式约束。单击增选/取消单个节点，节点菜单负责整棵加入/排除、显式连接路径等范围命令。
- 提取默认复制，可选剪切；新对话保留选中节点的所有版本及各自元数据、书签、会话配置。
- 复制按树图使用的 children 边投影选区，要求副本是单根、无环、无多父的树；原树的图外关联记录不应阻止合法选区复制。副本内部 parent 按所选边重建，原树不修复、不重连。
- 树图、选区分析与复制/剪切/删除共用 root 沿 children 可达的节点集合，独占性由这些 children 边决定。图外记录的 parent 声明或 children 列表不构成当前树的依赖，不阻挡正常子树操作；图外记录原样保留，不自动清理。可见树内缺失/歧义引用仍保守保护。若删除实际 root 会留下存储记录，仍保留 root，避免自动丢弃残留。
- 关联问题以消息角色和内容摘要说明，提供定位、高亮，图外/缺失记录明确标注；ID 仅作折叠技术信息，不能代替用户可读提示。
- 删除前预览实际可移除节点、受保护节点及相关未选依赖，让用户确认删除可删除部分，或保留选区返回调整。选到中间节点不再使其他独占部分整体失败；没有可移除节点时拒绝删除/剪切，不静默退化为复制。
- 复制/剪切要求选区连通且只有一个选区根节点。多个不连通区域允许计算并删除安全部分；提取前由用户显式补齐连接路径，不自动补选、重连或拆成多个会话。
- 剪切的新对话包含全部选区，原对话只移除已预览确认的独占部分。执行前校验最新计划与确认计划一致，变化时拒绝并要求重新预览。操作失败不修改原树，不创建半完成新对话。
- 保留未受影响的当前世界线路径；删除命中的后缀时停在最近保留祖先；删除整棵树允许得到空对话。
- 生成中禁止结构性删除/剪切。
- 协议范围：现有 OpenAI-compatible Chat Completions、Claude Messages、Gemini generateContent；不新增 Responses API。
- 正确解析流式/非流式 usage，保留输入、输出、缓存读/写、推理 token 明细，避免重复计数，不把未报告数据显示为真实的零。
- 思维链与正文分离，流式实时可见，最终独立折叠展示；不将结构对象、签名或加密数据作为文本显示。
- usage、思维链、耗时归属于特定 msg 的特定 version；rerun 新版本不覆盖旧版本，切换版本同步切换展示。不新增全局统计或计费系统。
- 优先普通对话，保留工具调用/agent 既有兼容，不扩展其统计职责。

## 验收重点

1. 共享路径分支剪切后，新对话包含完整选中路径；原对话只移除独占节点，剩余 parent/children/worldLine/bookmarks 一致。
2. 任意点击顺序得到相同的选择分析；中间节点与安全独占部分混选时，预览后只移除独占部分。零可移除节点、失效 ID、过期预览在任何副作用前失败。
3. 支持完整子树、任意集合、多处区域删除、整树、非当前世界线分支操作；不连通提取被拒绝，显式补齐后可提取，保留全部版本及 usage。
4. 三种协议的真实返回形状覆盖缓存与思维链；SSE 任意网络分片、末尾 usage 与无正文的推理阶段正确处理。
5. 消息栏显示当前 version 的基本用量，展开看明细；缺失数据不误显示为零；rerun 与历史版本切换不串数据。
6. 测试覆盖上述行为与失败路径；执行类型检查及发布构建，记录仍需思源应用内验证的 UI 行为。

## 不做

Responses API、请求端缓存策略/计费、全局消耗面板、agent 统计重构、恢复整树的撤销系统、对历史缺失用量的推测补算。
