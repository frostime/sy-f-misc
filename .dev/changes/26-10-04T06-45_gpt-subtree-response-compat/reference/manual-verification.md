# 思源应用内验收清单

以下是待执行的应用内交互验收，不是已通过的结果。离线测试与构建结果另见 verification.md。

## 子树

准备临时对话：`R → A → B`、`A → C`、`R → D`，当前世界线为 R/A/B，B 有两个不同模型/rerun 版本及 usage，A/B/C 有书签。

- [ ] 完整对话结构 → 提取子树，选择 Root=R、endpoint=B，默认复制；原会话不变，新会话只有 R/A/B，全部版本及书签可查看。
- [ ] 同样选择剪切，取消确认时选择和原树都不变；确认后原会话只删 B，R/A/C、R/D 的 parent/children 不变，书签 B 移除。
- [ ] 剪切生成的新会话中切换 B 的版本，回答、推理、缓存明细随之切换，不汇总不同版本。
- [ ] 原树中选择 Root=R、endpoint=A，删除和剪切明确报错；不能静默复制，不能丢失或重连 B/C，不能创建新会话。
- [ ] 同样的中间 endpoint 仍允许复制，得到 R/A。
- [ ] 选择 Root=R、endpoint=B/C，删除后保留 R/D，当前世界线停在 R；树视图刷新但对话框不强制关闭。
- [ ] 删除非当前分支 D 时，当前世界线不变。整树删除得到空树；关闭/重开对话不得从旧临时缓存恢复被删节点。
- [ ] 剪切整树后，原对话为空，新对话完整；插件重载后原对话不得恢复旧树。
- [ ] 回复生成中尝试提取、删除、剪切应拒绝。确认弹窗期间开始生成，执行时仍需拒绝。

## 普通对话与 rerun

对 OpenAI-compatible、Claude、Gemini 分别选择可返回 thinking/cache usage 的模型；优先使用自己的已配置服务，不为验收新增或修改密钥。

- [ ] 流式思考阶段只有独立“推理过程”区，正文不含 `<think>` 标签或 `[object Object]`；默认生成中展开、完成后折叠，可手动关闭。
- [ ] 正文与推理中的中文跨网络分片不丢失；末尾 usage 在正文结束后仍能更新。
- [ ] usage 显示当前版本的总量、输入、输出，展开看实际提供的缓存读取/写入、推理等明细；明细不再次加到总量。
- [ ] 返回明确的 0 显示为 0；服务未报告的字段不显示为 0。缓存值不能冒充输入总量。
- [ ] rerun 准备/生成中不显示旧版本的 usage、耗时或思维链；失败后也不继承旧版本数据。
- [ ] 切回旧版本能看到旧 usage；再切回新版本看到新 usage。版本预览面板同样显示预览版本的数据。
- [ ] 生成中不能切换/删除该消息的版本，但可预览既有版本。其他消息正常查看不受影响。
- [ ] 非流式结果的思维链和 usage 与流式语义一致。
- [ ] 暗色/亮色主题、窄聊天窗口、版本弹窗中用量展开布局正常。
