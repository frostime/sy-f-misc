# 思源应用内验收清单

以下为待执行或需重验的真实宿主步骤，不代表自动化浏览器测试已覆盖思源、设备同步或模型服务。结果另见 verification.md。

## 集合选择与执行

准备临时对话：`R → A → B`、`A → C`、`R → D`，当前世界线 R/A/B。B 有两个版本及各自 usage；A/B/C 有书签。

- [ ] 浏览时点击只显示详情；进入选择模式后详情动作退出，普通单击只增选/取消一个节点。
- [ ] 节点 ⋯ 和右键都能打开范围菜单，不改变选择。整棵加入/排除、查看内容、显式连接路径工作正常；查看内容、取消菜单不改变原树。
- [ ] 选择 B/C 两个不连通区域：可预览删除安全部分，不能直接复制/剪切；显式补齐 A 后成为可提取选区，不能自动加入 R。
- [ ] 选 R/A/B 并复制：新会话只有所选节点，全部版本、usage 和书签可查看；原会话不变。
- [ ] 同样选区剪切：预览清楚显示 B 移除、R/A 保留；取消返回原选区。确认后原会话只删 B，其他分支关系不变，新会话含全部 R/A/B。
- [ ] 混选中间节点和其他独占分支：不再整体拒绝，预览实际可移除部分和必须保留部分，只有再次确认才删除安全部分。
- [ ] 只有中间节点、没有安全可移除内容：复制可用，删除/剪切不能执行，不静默退化为复制。
- [ ] 有图外记录声明依赖选区、但没有对应树图连线：完整可见子树可复制、全部剪切/删除，不再出现 UNLISTED_DEPENDENT 提示；图外记录原样保留。切换 active path 或消息 version 后资格及移除范围相同。
- [ ] 本次真实结构案例：选择 20260909194229-6ciw1zw 并加入全部后代，应选中 9 个、可移除 9 个、保留 0 个。总节点显示当前根可达的 133 个，而非存储 map 的 2019 条。
- [ ] 关联提示显示角色和摘要，可定位高亮有关节点；图外/缺失记录明确标注，原始 ID 只在技术信息中。
- [ ] 操作确认期间原树变化：实际执行范围变化则拒绝，重新预览；切换其他会话后旧窗口不得操作新会话。
- [ ] 删除当前分支后停在最近保留祖先；非当前分支删除不改变当前路径。干净整树删除为空；重新打开、重载插件不能恢复旧节点，继续输入产生新 root。
- [ ] 干净整树剪切：新对话完整，原对话为空。若还有未选存储记录则 root 保留，不能清空 root 后遗留不可访问数据。
- [ ] 回复生成中结构操作拒绝；保存失败恢复原树、不残留半完成目标。预览/取消/定位绝不写历史。
- [ ] 大对话树（约 2000 节点）的单击、菜单、批量选择响应可接受，选择时不跳回根节点、不丢焦点。

## 普通对话与 rerun

对 OpenAI-compatible、Claude、Gemini 分别使用已有模型服务；不为验收新增或修改密钥。

- [ ] 流式推理独立显示，正文没有 `<think>` 标签或 `[object Object]`；推理生成中展开、结束折叠，可手动关闭。
- [ ] 中文跨分片不丢失；末尾 usage 正确更新；非流式与流式语义一致。
- [ ] 当前版本的总量/输入/输出可读，展开缓存读写与推理明细，不重复相加；未知不补 0，明确的 0 保留。
- [ ] rerun 不继承旧版本用量、耗时、推理；失败也不继承。切回旧/新版本时各自记录一致，版本预览亦正确。
- [ ] 生成中不能添加/切换/删除目标消息版本，但仍可预览旧版本、查看其他消息。
- [ ] 子树迁移后的版本切换及 JSON 历史保存/加载保持上述记录。
- [ ] 暗色/亮色、窄窗口、版本弹窗的布局正常。

## 兼容性

- [ ] 现有 standard/legacy 的简单工具调用能完成，不增加 agent 全局统计。
- [ ] 新构建需同时更新 index.js 和 pages/chat-world-tree.html，重载插件并重新打开树窗口；不能只替换 HTML 后继续使用旧 SDK 实例。
