# 对话树选择原型

当前评审入口：[selection-set.html](selection-set.html)。直接用浏览器打开，无需启动项目。

- [集合与操作权限预览](selection-set.png)
- [节点范围菜单预览](selection-menu.png)

## 已确认的方向

- 浏览和选择两个状态，通过明确按钮切换。
- 单击增选/取消单个节点，允许连续点选。
- 节点的 `⋯` 菜单或右键提供整棵加入、整棵排除等范围命令，不引入额外持久操作模式。
- 所选节点是一个集合；结构和执行条件从集合推导，而不是先限定 root/endpoint 再解释点击。
- 不隐式补选、重连，也不删除未选内容。

## 原型中待评审的部分

- 复制/剪切需要连通选区；分散选区可以显式补齐连接路径。
- 多棵完整的独立子树可统一删除；中间终点保留既有拒绝规则。
- 公共节点的保护仍保留：安全剪切/删除只移除独占部分，并明确显示实际移除数量。
- 操作状态说明、节点菜单内容、结果预览和布局是否合适。

这里的权限是产品建议，尚未实现成正式 API 契约。节点卡片样式、布局、12 条模拟数据不证明真实大树性能，也不作为正式样式定案。执行只展示模拟结果，不保存、不删除、不切换会话。

`tree-operations.html` 和 `paths.png` 是之前的“完整子树/指定路径”模式原型，用户已指出其模式切换增加负担，保留作迭代记录，不是推荐方案。

验证：inline JS 语法、6 项局部集合/权限检查通过；独立浏览器实例实测了进入/退出、连续点选、范围加入/排除、显式补齐、右键/Escape、查看内容、操作确认和模拟结果。正式 `src/` 未修改。
